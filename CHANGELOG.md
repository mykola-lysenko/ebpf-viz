# Changelog

All notable user-facing changes are documented here.

## [1.1.0] - 2026-06-30

### Added

- Standalone build and deployment flow, including Node 16 runtime smoke coverage for the packaged server.
- Remote BPF capture helpers for collecting inventory, networking, cgroup, map, and program data through an intermediate host.
- Packet-chain analysis for TC and cgroup networking programs, including pass/drop/redirect verdict summaries, tail-call awareness, side-effect labels, and detailed chain explanations.
- Large-program code rendering improvements, including worker-based CFG rendering, cached summaries, and safer fallbacks for very large control-flow graphs.
- Program table usability improvements, including resizeable columns and full-name tooltip behavior for truncated program names.
- Shared map hotspot detection to highlight maps used by multiple programs.
- Struct Ops visibility across the dashboard, kernel view, and networking view, including TCP congestion-control algorithm grouping.
- TCP congestion-control duplicate-instance detection, with explicit distinction between callback roles, loaded callback programs, and struct_ops instances.

### Changed

- The Network tab now separates packet-processing chains from TCP congestion-control struct_ops, making it clear that congestion-control callbacks affect TCP socket behavior rather than NIC packet verdicts.
- Struct Ops grouping now uses struct_ops map/BTF metadata when available and displays inference confidence/source labels.
- Standalone release artifacts are generated by GitHub Actions and validated on Node 16.

### Fixed

- Standalone runtime compatibility with Node 16 while keeping the build pipeline on modern Node.
- CI setup issues around pnpm version selection and Node runtime compatibility.
- Program-chain rendering bugs around TC direction labels and duplicate row numbering.
- C source/JIT rendering behavior for bpftool JSON output and line-number annotations.
